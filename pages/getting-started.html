Getting Started with Bully SE Mods

Complete installation guide for scripts, retextures, and tools. Follow these steps to start modding Bully: Scholarship Edition.

Prerequisites

Before installing any mods, ensure you have:

  • Bully: Scholarship Edition on Steam (PC)
  • ScriptHookV or equivalent script loader
  • Visual C++ Redistributables (2015-2022)
  • Backup of your Bully.exe and game files

Always back up your game files before modding. Mods can cause instability or prevent the game from launching.

Installation Methods

Method 1: Script Loader (Recommended)

Best for .lua and .asi scripts

  1. Download the latest Script Loader from our Downloads page
  2. Extract the archive to your Bully SE installation folder:
    C:\Program Files (x86)\Steam\steamapps\common\Bully Scholarship Edition\
  3. Place your .lua scripts in the scripts/ folder
  4. Place .asi plugins in the root game folder
  5. Launch the game — scripts load automatically

Method 2: Texture Replacement

For .txd and .dds retexture files

  1. Download TXD Tool from our Tools page
  2. Open your game's models/txd/ folder
  3. Import the downloaded .txd or .dds files
  4. Save and rebuild the archive
  5. Test in-game

Common Issues

Game crashes on launch after installing mods

Disable all mods, then re-enable one by one to identify the conflict. Check Troubleshooting for specific error codes.

Scripts not loading / nothing happens in-game

Ensure Script Loader is installed correctly. Check that scripts/ folder exists in your game directory. Verify .lua files have correct syntax.

Textures appear pink/missing

This means the texture file wasn't imported correctly or the TXD archive is corrupted. Re-import using TXD Tool and ensure you saved the archive.

Controller inputs not working with scripts

Some older scripts only support keyboard. Check the mod description for controller support. Our updated versions (v2.0+) include controller mappings.
